# 飞艇餐厅 R9 生产经营链路收敛审计 v0.1

> 状态：R9-01 已完成。审计日期：2026-08-20。本文件描述 R0—R8 完成后仍存在的生产接线缺口，不否定各领域模块本身已经通过的独立验收。

## 1. 结论

R0—R8 已完成模块边界、数据结构、算法、独立测试、兼容清理和稳定性验收，但正式客户端尚未让 R4—R6 的通用角色、订单、食谱 DAG、服务和单件物流模块接管日常经营。

当前生产组合根并行创建：

1. `GameplayRuntime`：正式时钟每秒推进，拥有早期 Cooking、Logistics、Restaurant 和 Procurement 经营状态，是 Operations UI、普通闲聊、旧故事观察和正式存档的主要来源；
2. `R6DemoApplication`：使用独立 fixture 和固定 ID，通过两个 Demo 命令一次性执行番茄炒蛋验收脚本，展示 R4—R6 新模块闭环。

这不是同一经营世界的两个读模型，而是两套互不等价的状态来源。R9 的目标是让已经验收的新领域模块成为唯一生产经营事实，并删除固定 Demo 和早期连续经营链路。

## 3. 当前权威状态判定

在 R9 完成前必须按以下方式理解代码：

- 正式日常经营事实仍来自 `GameplayRuntime`；
- R6 fixture 中的角色、任务、订单、库存、财务、餐盘、服务和货梯只属于固定验收场景；
- R6 Demo 的余额不是正式 Finance 余额；
- R6 Demo 完成状态不保存，不能作为玩家进度；
- R4/R5/R6 的“已完成”表示模块与纵向切片验收完成，不表示已经替换生产主循环；
- 新功能不得继续添加到 `GameplayRuntime` 或固定 R6 脚本，应进入 R9 通用生产运行时。

## 4. 目标所有权

R9 完成后的生产结构：

```text
GameRuntime（宿主、命令、时钟、发布）
        │
RestaurantApplicationRuntime（连续流程协调，不保存领域镜像）
        │
        ├── Character / Employment / Task / Movement
        ├── Customer / Order / Service
        ├── RecipeExecution / KitchenFacility / KitchenProduct
        ├── Inventory / Dishware / Storage
        ├── LogisticsDemand / FreightElevator / PersonnelElevator
        ├── LocalProcurement / Fleet / AutomaticProcurement
        └── Finance / Progression / Narrative adapters
```

每个领域模块自行保存权威状态。应用运行时只负责基于当前时间和领域事件调用流程协调器，不持有第二份订单、库存、角色或财务镜像。

## 5. 迁移约束

1. 不把 `R6DemoApplication.#runBusinessDay` 改造成更大的固定脚本；
2. 先建立可逐 tick、可多订单、可重建任务来源的通用应用运行时，再迁移 UI；
3. 迁移期间同一份销售只能进入一个 Finance，禁止 Demo 与正式经营同时结算；
4. 新模块存档必须使用稳定模块 ID，并提供现有 v2 gameplay 切片到新模块的明确迁移或安全重置报告；
5. Desktop 和 Management 先新增新读模型，再关闭旧字段，不能恢复总快照依赖；
6. 故事、闲聊和专注模式只订阅正式经营领域事件；
7. 固定 R6 Demo 保留为测试 fixture，最终从生产组合根、contracts 和管理 UI 移除。

## 6. R9 验收出口

- 正式客户端只存在一个经营世界和一个 Finance 余额；
- 不再暴露 `demo.submit-recipe-procurement`、`demo.start-business` 或 `r6Demo` 产品协议；
- 正式 tick 可以自然完成多桌来访、点单、DAG 烹饪、单件货梯、上菜、结账和清桌；
- Order、Customer、RecipeExecution、Task、Service、Inventory、Dishware、Logistics 和 Elevator 状态可保存恢复；
- 管理 UI 只展示正式经营切片；
- 故事与闲聊由正式顾客和餐点事件驱动；
- 旧存档迁移结果明确，完整回归、加速稳定性、Windows 常驻和视觉验收通过。
