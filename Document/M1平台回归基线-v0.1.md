# 空艇餐厅 M1 平台回归基线 v0.1

更新日期：2026-07-29

## 1. 目的

这份清单固定正式桌面壳进入 M2 前的质量基线。自动化通过不等于平台矩阵已经完成；
未验证项必须保留，不用“本机正常”代替 Windows 10／11、多 DPI 和多显示器结论。

## 3. 当前实机环境

- 系统：Windows 11 专业版；
- 版本：10.0.22631（23H2）；
- 首发支持范围：Windows 10／11；
- 当前正式用户配置：首次设置尚未确认，因此还未生成正式 `settings.json`；
- 当前结论仅代表这台机器，不能覆盖 Windows 10、其他 GPU 或多显示器组合。

## 4. 人工回归矩阵

### 4.1 本机优先验证

- [ ] 完成首次引导，选择目标显示器和置顶策略；
- [ ] 退出并重新启动，确认显示器、置顶、表现模式和管理窗口位置恢复；
- [ ] 正常、低动态、安静三种模式可以实时切换；
- [ ] 安静模式下环境层停止，飞艇、餐厅与主进程仍然正常；
- [ ] 飞艇与餐厅可点击，空白、缆车、蒸汽和港口占位保持穿透；
- [ ] 管理窗口打开和关闭不会抢走桌面工作流中的长期焦点；
- [ ] Windows 缩放 100%、125%、150% 下视觉与命中区域一致；
- [ ] 任务栏位于下、上、左、右时，餐厅和轨道均使用工作区而非全屏边界；

### 4.2 多显示器与系统状态

- [ ] 选择副显示器后桌面世界完整迁移；
- [ ] 拔掉目标显示器后回退主屏并出现重新确认提示；
- [ ] 重新接入显示器后不自动跳回旧屏；
- [ ] 锁屏、睡眠、唤醒后透明窗口、动画和输入状态恢复；
- [ ] Explorer 重启或任务栏尺寸变化后桌面窗口重建且不出现白底；

### 4.3 长时间运行

- [ ] 运行 30 分钟，无明显 CPU／GPU 异常和窗口泄漏；
- [ ] 运行 2 小时，记录内存、GPU、句柄和 renderer 数量；
- [ ] 反复打开／关闭管理窗口 30 次，不增加 IPC 订阅或残留窗口；
- [ ] Steam Overlay、录屏、全屏应用切换时层级行为可接受。

## 5. 进入 M2 的处理原则

- 自动化基线和当前 Windows 11 透明合成已经通过，可以开始 M2；
- 首次引导重启恢复、DPI 和任务栏方向必须在 M2 第一批开发期间穿插完成；
- Windows 10、睡眠恢复和 2 小时常驻测试在 M1 正式退出前完成；
- 若发现白底、误点击、抢焦点或跨屏错误，按 P0 处理并暂停玩法接线；
- 纯视觉错位若不影响点击和桌面工作，可记录后在正式美术接入时处理。
