# 空艇餐厅 M3 食谱叙事系统基线 v0.1

更新日期：2026-07-30

状态：M3-01／M3-02／M3-03 基础切片已接入，正式角色、首位故事客人、第一张情感
食谱、21 组普通闲聊和 7 组关键剧情对白已经数据化；普通闲聊运行时选取已接入，
桌面头顶气泡已实现，首次体验关键剧情调度待实现

## 1. 本阶段目标

M3 要证明“食谱是情感载体”，同时保持桌面挂机游戏低压力、不抢焦点的体验。
故事内容不能仅作为一次性弹窗存在，而要能够被食谱日志保存、暂停和回看。

## 2. 当前已实现

- ContentRegistry 支持角色、客人、地点、对话说话人、普通闲聊、关键剧情对白、
  故事事件、食谱日志和本地化文本；
- 校验稳定 ID、角色／地点／说话人／食谱／菜品／前置事件／剧情对白引用及本地化键；
- 校验失败会集中输出编剧／策划可读的问题列表；
- NarrativeSystem 支持在线条件进度、优先级、前置事件、去重、已读、完成和恢复；
- 故事进度随现有 schema v1 存档保存，旧 M2 存档可直接加载；
- 新增或移除故事事件不会使旧存档失效；
- 管理窗口提供默认折叠的“食谱故事”区，不弹窗、不抢焦点；
- 锁定条目显示在线经营进度，解锁条目可以标记已读并收录到食谱日志；
- AmbientDialogueSystem 按地点、营业上下文、熟悉度、故事前置、权重、冷却和单次
  会话次数选择普通闲聊，并逐句生成运行时对话快照；
- 安静模式会拉长普通闲聊间隔；当前熟悉度暂用累计售卖数量作为 Demo 代理；
- 普通闲聊只属于当前在线会话，不写入存档，也不会在下次启动或离线结算后补发；
- 桌面场景从正式内容表解析当前行的说话人和本地化文本，将小型气泡稳定绑定到三个
  餐厅客人站位；多人闲聊会随说话人切换座位；
- 气泡不写入 SemanticHitMap，不会在餐厅之外新增可点击区域。

## 3. 在线与离线边界

故事系统没有按时间推进的入口，只能接收 GameRuntime 明确传入的在线经营增量。

- 应用启动时先完成离线经营结算，再建立 NarrativeSystem；
- 启动前累计的销量只作为在线基线，不会解锁、排队或补发故事；
- 应用运行后的新经营行为才会增加故事条件进度；
- 读取、完成和回看由显式类型化命令处理；
- 未来港口叙事也必须沿用这一边界。

## 4. 正式内容接入

首段正式内容已替换原有角色与故事占位：

- 正式角色：`character.baiyecheng`、`character.otto`、`character.martha_bell`、
  `character.thomas_bell`；
- 故事客人：`customer.martha_bell`、`customer.thomas_bell`；
- 首次正式故事事件：`story.bell_stew_first_service`；
- 正式食谱日志：`journal.bell_hearth_stew`；
- 灰羽航标塔地点、25 位对话说话人、21 组普通闲聊和 7 组关键剧情对白；
- 为兼容已经生成的 M2 存档，食谱与菜品仍使用稳定 ID `recipe.homecoming_stew` 和
  `dish.homecoming_stew`，显示名称已改为《贝尔家的炉火炖菜》。

普通闲聊已经能够进入 GameRuntime 快照，但当前桌面场景还没有把该快照绘制成角色
头顶气泡。7 组关键剧情对白目前是经过校验的内容数据，尚未接入首次体验的阶段调度。

## 5. 下一步接入工作

已经确认的正式剧情方向另见《M3 剧情方向决策记录 v0.1》，包括：

- 白夜城是慈祥、略显笨拙的退役炊事班班长，负责做菜；
- 旧炊事笔记同时记录战地食谱与战士愿望，并成为最初的旅行线索；
- 白夜城为探望旧友、兑现愿望，也因熟客无法再来而把厨房带上天空；
- 原餐厅作为家港保留，飞艇执行可返回、可重访的巡回营业；
- 拥有语言能力的退役魔道机器人奥托负责乘缆车送餐；
- 旧愿望逐步完成，新客人、熟客和新食谱也会在旅途中持续增加；
- 第一位故事客人为退役通讯兵、灰羽航标塔守塔人玛莎·贝尔；
- 玛莎与憨厚老实的丈夫托马斯·贝尔共同生活；
- 第一张情感食谱为夫妻二人在家最喜欢吃的《贝尔家的炉火炖菜》；
- 角色使用头顶小型场景气泡对话，不采用横跨屏幕的大型对话框。

普通客人首批 21 组日常气泡见《M3 普通客人日常对话 Demo v0.1》，完整首段编排见
《M3 首次 15—30 分钟体验脚本 v0.1》。普通闲聊头顶气泡已经接入；下一步实现关键
剧情阶段调度、贝尔夫妇故事订单和食谱意义变化，随后补齐重要对白暂停、恢复与回看。
长主线外部问题、白夜城与奥托的相遇经历以及最终美术与平衡数值不阻塞本轮纵向
切片。
